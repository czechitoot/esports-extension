# Esports Helper

## Disclaimer

Esports Helper is an independent, unofficial extension. It is not affiliated with or endorsed by the organizations or services whose pages it enhances.

Esports Helper is provided as is, without warranty. Install and use it at your own risk. No support is provided, and continued compatibility or future updates are not guaranteed.

## Get

[Get the Esports Helper extension!](https://chromewebstore.google.com/detail/ijoihdmdnameopfehjlbcjlbpmebknfe)

## Permissions

- The only extension API permission is `storage`, used to save preferences locally in Chrome/Chromium.
- Chat text and match information are processed locally; they are not saved or sent to the developer.
- There is no advertising, analytics, tracking, or remotely loaded code.
- Opening a bookmark or chat link does not grant the extension access to the destination website.

See [PRIVACY.md](PRIVACY.md) for details about data handling.
