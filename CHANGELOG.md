# Changelog

## 0.1.1

- Rebranded as Esports Helper with a generic gaming identity.
- Simplified documentation and retained the existing site access restriction.
- Renamed the default match-site bookmark to Match dashboard, preserving custom labels.
- White controller icon on a dark red background, sized for toolbar visibility.

## 0.1.0

First public release.

- Editable game colors for Dashboard and schedule rows, enabled by default.
- Clickable links in existing and newly received chat messages, enabled by default.
- Optional relocation of match chat below match details, disabled by default.
- Responsive match detail layout, enabled by default.
- Editable popup bookmarks, with match-site and Smash Helper defaults.
- Settings page with Save settings in the header.
- Blue N and white headset icon.
- Access limited to the supported match site; preferences stored locally.
